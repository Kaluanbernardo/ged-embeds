# ged-embeds

Peças interativas do Portal da GED (SENAI-SP) para incorporar no SharePoint pelo web part Inserir.
A fonte canônica fica no vault (`deliverables/pagina-sharepoint-ged/embeds/`); este repositório só publica pelo GitHub Pages.

- `hero-botoes.html`: os quatro botões do hero. Links por parâmetro (`?sistemas=`, `?documentos=`, `?programas=`, `?equipes=`, só `https://`); `?alvo=_blank` abre em nova aba.
